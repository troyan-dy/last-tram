# Решения «Последнего трамвая»

Здесь собраны принятые договорённости: какой выбор сделали, из каких вариантов и почему. При расхождении с ранними эскизами, прототипом или обсуждением в Issues действует соответствующий ADR.

| ADR | Решение |
| --- | --- |
| [0001](0001-tram-network.md) | Игрок проектирует сеть; вагоны следуют по маршрутам сами. |
| [0002](0002-passenger-choice.md) | Житель сравнивает поездку от двери до двери с ходьбой; тариф влияет на выбор. |
| [0003](0003-visible-demand.md) | Игрок видит причины выбора жителя и прибытия к месту назначения. |
| [0004](0004-seeded-city.md) | Весь город генерируется по одному сиду до открытия районов. |
| [0005](0005-expansion-rings.md) | Зона обслуживания растёт целыми кольцами; город ставит цели по результату. |
