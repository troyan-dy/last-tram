# Решения «Последнего трамвая»

Здесь собраны принятые договорённости: какой выбор сделали, из каких вариантов и почему. При расхождении с ранними эскизами, прототипом или обсуждением в Issues действует соответствующий ADR.

| ADR | Решение |
| --- | --- |
| [0001](0001-tram-network.md) | Игрок проектирует сеть; добавление поездов на маршрут сокращает интервал. |
| [0002](0002-passenger-choice.md) | Житель сравнивает поездку от двери до двери с ходьбой; тариф влияет на выбор. |
| [0003](0003-visible-demand.md) | Слой «Потоки» и фокус на здании или жителе помогают увидеть спрос и понять выбор поездки. |
| [0004](0004-seeded-city.md) | Весь город генерируется по одному сиду до открытия районов. |
| [0005](0005-expansion-rings.md) | Зона обслуживания растёт целыми кольцами; город ставит цели по результату. |
| [0006](0006-isometric-city.md) | Изометрия, обзор всей открытой зоны и плотный панельный центр: перед путями дома ниже, за ними — выше. |
| [0007](0007-daily-demand.md) | Спрос повторяется в течение суток: утром на работу, вечером те же жители возвращаются домой. |
| [0008](0008-roads-and-stops.md) | Ценник на дороге покупает путь одним нажатием; место остановки выбирает игрок. |
