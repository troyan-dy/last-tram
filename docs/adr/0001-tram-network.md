# 0001. Игрок управляет сетью, а не поворотами одного вагона

В [ранней головоломке](../concept.md) игрок выбирал следующий перегон одного вагона. Для браузерного тайкуна выбрана другая роль: проектировать сеть, которая сама обслуживает пассажиропотоки. Интерес — заметить неудобную связь, изменить её и увидеть результат для жителей.

Путь — физические рельсы; маршрут — порядок остановок. Игрок прокладывает пути, задаёт и меняет маршруты, покупает вагоны и переводит их между маршрутами. Несколько маршрутов могут делить участок пути. Так продление маршрута и покупка вагона решают разные задачи: первое связывает новые места, второе может сократить ожидание на существующей линии.
