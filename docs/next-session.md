# Следующее обсуждение: как выглядит трамвайный город

Игровые решения собраны в [журнале ADR](adr/README.md). Рабочий ориентир для графики — минимализм. Перспектива и стиль ещё не выбраны: среди вариантов есть пиксельный 2D-город и объёмный low-poly. Интересующая автора деталь — дом при наведении становится полупрозрачным, если загораживает маршрут.

Для сравнения направлений можно взять одну сцену из концепции: жители идут из жилого квартала на рынок вдоль трамвайной линии. Видно ли, кто проходит мимо остановки? Можно ли выбрать этого человека и проследить его путь? Если затем выбрать рынок, понятно ли, откуда к нему приходят пешком, а откуда приезжают?

Два эскизных замысла из обсуждения ранней головоломки тоже можно примерить к этой сцене:

- **Бумажная схема диспетчера.** Молочная бумага, тёмные рельсы, очереди из маленьких билетов со значком назначения: дерево для парка, часы для вокзала. Проверить, удастся ли различить потоки и при этом сохранить ощущение живого города.
- **Город в синий час.** Часы на фасаде вокзала, полосатый навес рынка, тёплый свет в окнах вагона. Проверить, не теряются ли среди деталей пешеходы, остановки и путь между ними.

Это источники визуальных идей, а не утверждённое оформление.
