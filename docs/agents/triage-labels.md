# Метки для разбора задач

Названия ролей совпадают с метками в GitHub Issues:

| Роль / метка | Когда применять |
| --- | --- |
| `needs-triage` | Задачу ещё предстоит разобрать. |
| `needs-info` | Для решения нужно уточнение от автора. |
| `ready-for-agent` | Задача описана достаточно подробно, чтобы агент мог выполнить её самостоятельно. |
| `ready-for-human` | Для выполнения нужен человек. |
| `wontfix` | Принято решение не выполнять задачу. |
