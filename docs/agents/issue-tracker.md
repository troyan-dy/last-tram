# Трекер: GitHub Issues

`/to-ticket` — этап публикации **задач на работу** в [Issues проекта](https://github.com/troyan-dy/last-tram/issues). Его начинает пользователь отдельным вызовом. Источник договорённостей — [ADR](../adr/README.md); создание ADR, завершение обсуждения или слияние PR не запускает публикацию задач.

По `/to-ticket` прочитай указанные решения и проверь существующие Issues, чтобы не создавать дубликаты. Предложи проверяемый результат и критерии приёмки каждой задачи, укажи реальные зависимости; публикуй согласованный набор. В описании задачи дай ссылку на соответствующий ADR вместо копии спецификации. Новым готовым задачам присваивай `ready-for-agent`. Перед первой записью проверь `gh repo view --json nameWithOwner` или явно укажи `--repo troyan-dy/last-tram`.

| Действие | Команда |
| --- | --- |
| Найти открытые задачи с меткой | `gh issue list --state open --label <метка>` |
| Прочитать задачу и обсуждение | `gh issue view <номер> --json number,title,body,labels,comments` |
| Создать задачу | `gh issue create --title "..." --body-file <файл>` |
| Изменить метку | `gh issue edit <номер> --add-label <метка>` или `--remove-label <метка>` |
| Объяснить результат и закрыть задачу | `gh issue comment <номер> --body "..."`, затем `gh issue close <номер>` |

Если уже есть родительская задача, связывай её части как подзадачи GitHub. Зависимость «нельзя начать, пока не закончена другая задача» отмечай как *blocked by*. Если такая связь недоступна, укажи `Part of #<номер>` или `Blocked by: #<номер>` в начале описания.

**PRs as a request surface: no.**
