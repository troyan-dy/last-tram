# Последний трамвай

Этот репозиторий предназначен для разработки «Последнего трамвая» — браузерной игры о трамвайных пассажиропотоках.

## Интерфейс и возможность поиграть

- Перед реализацией нового экрана или изменением дизайна существующего покажи пользователю черновик: макет или интерактивный прототип с расположением элементов, основными состояниями и действиями игрока. Дождись явного согласования именно этого интерфейса. Согласование механики, стиля города или плана работ не заменяет согласование макета страницы.
- При каждой передаче результата дай способ сыграть. В PR и сообщении пользователю укажи, как открыть **именно версию PR** локально; после слияния в `master` проверь игру на GitHub Pages и дай прямую ссылку. Если публикация заблокирована, назови причину и дай проверенную локальную версию. [Порядок запуска и публикации](docs/agents/play-access.md).

## Agent skills

### Issue tracker

Только по явному вызову `/to-ticket` оформляй работу в GitHub Issues. См. [правила публикации задач](docs/agents/issue-tracker.md).

### Triage labels

При разборе задач используем пять стандартных меток. См. [значения меток](docs/agents/triage-labels.md).

### Domain docs

Итог обсуждения (контекст, варианты, согласованный выбор и его причины) записывай в `docs/adr/`. В этом проекте `/to-spec` создаёт или актуализирует ADR и заканчивается ссылкой на него, без создания Issue. Термины веди в `GLOSSARY.md`, гипотезы — отдельно от решений. См. [порядок ведения ADR](docs/agents/domain.md).
