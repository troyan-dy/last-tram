# Последний трамвай

## Поездки

**Поездка пассажира** — путь одного жителя из исходной точки до его места назначения. Посадка в вагон сама по себе не означает, что поездка завершена.

**Время поездки** — время, которое пассажир тратит, чтобы добраться до места назначения. Оно включает как минимум ожидание трамвая и время в вагоне.

**Пассажиропоток** — количество пассажиров, которым за определённое время нужно добраться из одной точки города в другую.

## Город

**Район** — часть города, которая открывается для игрока целиком. В начале игры открыт один район; затем к нему можно присоединять соседние.

**Сид города** — значение, по которому можно заново получить ту же карту города. Для новой игры можно взять случайный сид или указать уже знакомый.
